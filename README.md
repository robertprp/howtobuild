# HowToBuild.dev

Find the tools and stacks to build your next project at [howtobuild.dev](https://howtobuild.dev).

- **Discover projects** — browse by category and ecosystem, or search for tools that fit your use case.
- **Explore trending repositories** — compare tracked GitHub projects by star growth over 7, 30, or 49 days.
- **Choose your stack** — explore guides and customize supported framework, auth, styling, database, and service choices.
- **Start building** — copy a starter prompt or download it as Markdown. TypeScript starters use pnpm.
- **Contribute** — register freely, submit a project, suggest corrections, and follow your submission through editorial review.

Browsing needs no account. Community submissions are reviewed before publication.

For self-hosting and development, see [environment configuration](.env.example). Grant a verified account admin access with `pnpm admin:grant --email you@example.com`, then review submissions at `/admin/submissions`.
